# Les matrices en CSS

Un parcours en 7 étapes et 2 démos pour comprendre les transformations CSS et les matrices qui se cachent derrière : translation, échelle, inclinaison, rotation, composition, puis `matrix3d()` et la perspective.

Chaque dossier est une page autonome (`index.html`, `style.css`, `script.js`). Ouvrez `index.html` à la racine dans un navigateur pour accéder au sommaire. Aucune installation n'est nécessaire.
